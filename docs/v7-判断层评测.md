# v7：判断层评测——第一次量「模型裁判」自己

> 这一轮之前，`app.py` 里那层「让模型判断资料够不够」的逻辑，
> **一次都没有被评测过**。
> `eval.py` 量的是纯检索 + 纯阈值，根本不过这一层。
> README 里那个「拒答 80%」，描述的不是线上真实行为。

## 结论

判断层**保留**。理由不是它让总分变高（它没有），是它把「答错」换成了「不答」。

| 口径 | 纯阈值 | 判断层 |
|---|---|---|
| 答出 | 26 | 20 |
| **真答对**（检索命中） | 23 | 19 |
| **答非所问**（检索没命中还答了） | 3 | **1** |
| 精确率 | 88.5% | **95.0%** |
| 召回 | 79.3% | 65.5% |
| 该拒的拒掉 | 8/10 = 80% | **10/10 = 100%** |
| **总正确**（答对 + 拒对） | 31/39 = 79.5% | 29/39 = 74.4% |

**总分低 5 个点。** 换来的是：答错的从 5 条（3 条答非所问 + 2 条该拒没拒）降到 1 条。

代价也写清楚：**多误拒 5 条**——用户问得出答案的问题，被系统挡回去了。

选它的判断依据：教务处问题上，**答错比不答危险**。学生拿着错的学分要求去办事，比多问一句更糟。而且拒答不是死路，会给「去哪查、点哪里」。

## 判定链（现在的真实流程）

```
问题
 ├─ 闲聊？ ──是──→ 固定话术（不检索、不调模型）
 ├─ best < 0.60 ──→ 拒 + 指路
 ├─ 0.60 ≤ best < 0.70 ──→ 调模型判断
 │     ├─ 能 → 答
 │     └─ 不能 → 拒 + 指路
 └─ best ≥ 0.70 ──→ 直接答
```

## 三次判据，每次都有数字

| 版本 | 判据 | 该答 29 条里的结果 |
|---|---|---|
| 第一版 | 「资料能不能回答这个问题」 | 看到体育课老师名单就说能答数学老师——太松 |
| 第二版 | 「必须有直接回答的内容，且摘出依据」 | 答出 17 条，**误杀 12 条**——太严 |
| **第三版** | 「有能实质帮到用户的就行，拿不准倾向能」 | 答出 20 条，真答对 19 |

**第二版为什么错得离谱**：问「学生证丢了急用怎么办」，资料里 5 篇全是《补办学生证通知》，模型却说：

> 不能 | 原因：资料主要描述了补办学生证的流程，但**没有提及急用时的特别处理方式**。

它判得"没错"——资料确实没写"加急"。但**用户要的就是补办流程**。

我把判据定成了「必须完整覆盖问题的每个限定词」，而应该是「有没有能帮到用户的内容」。

**「能不能答」是连续量，我当成了布尔值。**

## 这一轮最大的教训：口径错了两次

**第一次**：只看「最终答了没有」，把「答出 26 条」当成「答对 26 条」，得出「判断层净亏 7 条」的结论。实际上那 26 条里有 3 条是答非所问（问毕业证，召回的全是学生证通知）。

**第二次**：加了口径之后，我手工推「判断层答出的 20 条全部命中，一条错都没有」——脚本跑出来是 **19 对 1 错**。

**两次错在同一个地方：用手推代替了跑脚本。** 评测脚本的价值就在这——它不会帮我圆场。

## 闲聊识别（这一轮唯一净赚的）

规则判断，不调模型：

```
认出 8/8：你好 · 在吗 · 谢谢 · 你是谁 · 你能干什么 · 您好呀 · hello · 好的
不误伤 3/3：你好，转专业要什么条件 · 我想问问绩点2.1能不能拿学位 · 谢谢，那挂科了要重修吗
```

实现方式是**把问候词剥掉，看还剩不剩实质内容**——
所以「你好，转专业要什么条件」剥掉"你好"还剩正文，不会被误判成闲聊。

为什么用规则不用模型：
1. 这类问题不需要理解；
2. 要在检索之前拦住，多一次调用就是多 2 秒白等；
3. 判错了代价不对称——**漏判**只是回到原来的拒答流程，**误判**是把真问题当闲聊答非所问。

## 成本

**76% 的查询会进判断层**，每条多一次模型调用（2–5 秒）。

这是个真实代价，不是"无所谓"。要优化的话方向是收窄灰区（比如 0.60–0.65），但那样会漏掉 0.65–0.70 的误答。

**没算过钱，只算了比例。**

## 遗留

| 项 | 说明 |
|---|---|
| 灰区占了 76% | 每 4 个问题有 3 个要多等 2–5 秒。要不要收窄灰区，得先量「收窄后少拦下多少误答」 |
| 3 条误杀 | 大二转专业、家里有事能请多久假、重修几次会拿不到学位。都是「问题里有资料没写的限定词」 |
| 1 条答非所问 | 「转专业要多少绩点啊」——相似度 0.734 很高，但召回的《转专业通知》里没有 3.00 这个数字 |
| 判断层用免费 7B | 换更大的模型可能同时提精确率和召回，但每条再慢几秒 |
| 评测集 39 条 | 太少。判断层这种"边界判断"，至少 100 条才有统计意义 |
