# v9：判断层稳定吗——单批稳定，跨批漂移

> 起因：`本硕连读是不是直接读研`（相似度 0.703）两次跑结果不同。
> 如果判断层本身会变，那 v7、v8 里所有数字都不可信。

## 一、先说怎么测的

判断层的随机性不在检索（向量、BM25、融合都是确定的），只在 LLM 调用。

所以：**检索跑一次，判定跑 N 次**，看同一份资料下结论会不会变。

```python
res, sim = r.search(q, k=5, rewrite=True, vec_mode="orig")   # 一次
votes = [judge.check_answerable(q, ctx, client, MODEL) for _ in range(N)]   # N 次
```

## 二、单批次内：稳定

| 批次 | 样本 | 次数 | 摇摆 |
|---|---|---|---|
| 该答集 | 29 条 | × 3 = 87 次 | **0** |
| 拒答集 | 10 条 | × 5 = 50 次 | **0** |

同一批次里，每道题的 N 次判定**完全一致**——要么全票能，要么全票不能。

## 三、跨批次：漂了

同一道题、同一份资料，在不同时间跑，结论会变：

| 问题 | 14:50 全量实验 | 15:05 v8 评测 | 17:15 稳定性测量 |
|---|---|---|---|
| 我绩点2.5能不能毕业 | 能 | 能 | **不能（3/3）** |
| 本硕连读是不是直接读研 | 能 | 不能 | **不能（3/3）** |

**注意第三列是 3 次全票「不能」**——它不是因为某一次抽风，而是整个批次都站在另一边。

## 四、这意味着什么

1. **单次评测的数字有批次噪声。** v8 里那个「答对 21/29 = 72.4%」不是精确值，换一个时间跑，可能是 19 或 23。
2. **同一个问题，用户今天问得出、明天问不出来。** 这不是"偶尔抽风"，是一整个下午都这样。
3. **`temperature=0` 不等于确定。** 模型服务端可能有多副本/负载均衡，或者上游悄悄换了量化版本。

## 五、影响评估

- v7/v8 的结论**方向不变**（判断层比阈值精确、拆闸门后答非所问归零），因为这些差异都是数条量级。
- 但**具体数字不可引用为精确值**。写进 README 时应标注「一次测量的结果，有批次噪声」。

## 六、能不能修

| 方案 | 做法 | 代价 |
|---|---|---|
| 多批次评测 | 同一套题不同时间跑 3 次，报区间不报单点 | 评测时间 ×3 |
| 判定缓存 | 同一问题+同一资料，记住上次判定 | 掩盖问题，不是修 |
| 换模型 | DeepSeek 官方 / 更大参数模型 | 更慢，可能花钱，**未验证是否更稳** |
| 固定后端 | 需要服务商支持"固定实例"，个人做不了 | — |

**目前只做过第一项的最小版本**（这次测量就是）。其余三项都**没验证过**，不能当结论写。

## 七、这一轮顺带做的两件事

### 测试：23 个用例，不联网

`tests/test_judge.py` 覆盖判断层的全部纯函数：

- `is_smalltalk`：8 个应认出 + 3 个不应误伤（「你好，转专业要什么条件」）
- `parse_verdict`：「能但没给依据」必须判 False——这是模型最常见的偷懒方式
- `build_probe`：问题、资料都在；3000 字截断
- `check_answerable`：假 client，覆盖正常、上游异常、模型名透传

**证明「没联网」的方式有两个：**

1. 0.1 秒跑完 23 个用例（真联网不可能这么快）
2. 换一套假 key + 黑洞 base_url（`http://127.0.0.1:9/v1`）重跑，仍然 23 passed

第 2 条是关键：光说"测试通过了"证明不了它没联网。

### CI：第一次绿

`.github/workflows/test.yml` 两个 job：

- `unit`：正常跑
- `offline`：假 key + 黑洞地址再跑一遍

**不装 `requirements.txt`**。里面是 chromadb、pymupdf、pywin32 这些重依赖，而测试只用标准库。
装了全套依赖，测试通过就只能说明"环境齐全"，说明不了"这些代码不依赖外部环境"。

## 遗留

| 项 | 说明 |
|---|---|
| 跨批次漂移没有解 | 只能靠多批次评测报区间，或者换模型（未验证） |
| 评测集 39 条 | 样本太小，±2 条就是 5 个百分点，和批次噪声一个量级 |
| CI 只覆盖 judge | `retrieval`、`chunking`、分页解析这些还没有测试，需要至少一份不联网的纯函数测试 |
