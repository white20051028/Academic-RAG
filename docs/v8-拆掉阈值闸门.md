# v8：拆掉那道 0.60 的闸门（2026-11-06）

> 起因是一句用户测试：「我想服兵役」。
> 系统说不知道——可《学籍管理规定》里白纸黑字写着答案。

## 那句话

用户在界面上问「我想服兵役」，得到的是拒答：

```
最高相似度 0.544   低于可信阈值 0.60 → 直接拒
```

但检索出来第一条就是《西安科技大学本科生学籍管理规定（修订）》，里面有：

> 在校学生应征参加中国人民解放军（含中国人民武装警察部队），学校保留其学籍至退役后2年。

**答案就在第 1 条资料里，被一个分数闸门拦住了。**

## 根因：混合检索只在排序上混合，在判定上只用了向量一路

```python
# tools/retrieval.py
vec_ids, best_sim = self._vector_ids(query, pool)   # best_sim 只来自向量路
bm25_ids = self._bm25_ids(bm25_query, pool)          # BM25 的分数算完就丢了
```

BM25 路明明字面命中了"服兵役"这三个字，但这个信号在「拒不拒」这一步**完全没参与**。

而 `app.py` 的判定链是：

```
best < 0.60  →  直接拒（判断层根本没机会看一眼）
```

**判断层其实能答。** 单独验证：

```
判断层说：能 | 依据：在校学生应征参加中国人民解放军（含中国人民武装警察部队），学校保留其学籍至退役后2年。
```

它一字不差地摘出了原句——但这个判断从来没机会发生。

## 实验：既然阈值分不开，还要它干什么

v6 已经证明：该答的最低分 0.557、该拒的最高分 0.619，**两个分布重叠**，任何阈值都必然同时犯错。

那干脆把 39 条**全部**送进判断层，看它自己能不能撑住：

| 方案 | 真答对 | 正确拒答 | 总正确 | 答非所问 | 该拒没拒 | 误拒 | 进判断层 |
|---|---|---|---|---|---|---|---|
| 纯阈值 | 23 | 8 | 31/39 | **3** | **2** | 3 | 0% |
| 阈值 + 判断层（改前） | 19 | 10 | 29/39 | 1 | 0 | 8 | 76% |
| **全量判断层（改后）** | **21** | **10** | **31/39** | **0** | **0** | 8 | 100% |

**总分和纯阈值打平，但两类危险错误都归零。**

代价全部转移到「误拒」——用户拿不到答案。这是**安全方向**：拒答会说清为什么、去哪查，而答错会把学生带沟里。

## 现在的判定链

```
问题
 ├─ 闲聊（规则） ──→ 固定话术
 ├─ 相似度 ≥ 0.78 ──→ 直接答（快速通道，实测口语集最高 0.743，基本不触发）
 └─ 其余 ──→ 判断层
             ├─ 能 → 答
             └─ 不能 → 拒 + 指路
```

**相似度不再决定「答不答」，只用于两件事**：界面显示检索质量、快速通道跳过判断层。

界面上那个「相似度下限」滑块已删除——它已经不影响任何判定，留着只会误导。

## 代价

**100% 的查询多一次模型调用（2–5 秒）。**

「服兵役」这条现在能答了，代价是每条问题都要等判断层。这是有意的取舍：**宁可慢，不可错。**

## 新发现：判断层不稳定

`本硕连读是不是直接读研`（相似度 0.703）：

- 第一次跑（全量实验）：判「能」
- 第二次跑（拆闸门后验证）：判「不能」

`temperature=0` 也不保证完全确定（上游可能做批处理、模型版本也可能微调）。

**意味着：边界样本的判定会翻转。** 单次评测得到的数字，有 ±1~2 条的噪声，不能当成精确值。

这不是可以忽略的小问题——如果某个问题恰好落在边界，用户可能今天能问、明天问不出来。

## 遗留

| 项 | 说明 |
|---|---|
| 判断层不稳定 | 同一问题两次判定可能不同。要么多次采样投票，要么提高 `temperature` 一致性的可控性，要么换更稳定的模型 |
| 100% 多一次调用 | 快速通道 0.78 形同虚设（口语集最高 0.743）。要省时间只能接受更高的误答率，或者换更快的判断模型 |
| 8 条误拒 | 其中 5 条是检索本身没命中（毕业证、补考没过、翘课、延毕、转专业绩点），判「不能」是对的；真正误杀的是 3 条（大二转专业、家里有事能请多久假、重修几次会拿不到学位） |
| BM25 信号仍未用于判定 | 这轮是绕过了它（直接全部送判断层），不是用它。真正的修法可能是「BM25 高分 + 向量低分」时给一个加分，但那是另一个实验 |
| 评测集 39 条 | 太少。判断层有 ±1~2 条噪声，39 条样本下这个噪声能改变 3 个百分点 |
