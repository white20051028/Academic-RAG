## 三、加题之前，先校验了旧题

拿 47 条去对 1084 个 chunk，发现 3 处对不上。其中 2 处是**旧题**：

### ① `翘课会怎么样` —— 标了「旷课」@《学籍管理规定》

实际情况：

```
《学籍管理规定》里「旷」字出现 0 次
                      「缺课」出现 2 个 chunk
```

原文写的是：

> 第十二条 未经允许，学生单门课程的累计**缺课时数**达到或超过该课程规定学时数的**三分之一**，成绩按"0"分记。

而「旷课」这两个字，全语料只出现在**《辅修专业管理办法》**里（辅修无故旷课达 1/3 学时 → 取消辅修资格）。

### ② `延毕要怎么申请` —— 标了「延长学习年限」@《学籍管理规定》

实际情况：

```
《学籍管理规定》里「延长」出现 0 次
「延长学习年限」只在《辅修专业管理办法》和《本硕连读培养管理办法》里
```

而且那两处说的都是「**不**延长」：

> 学生应在其主修专业学制内完成全部辅修课程，辅修专业学习**不延长**学习年限。

**语料里根本没有「延长学习年限怎么申请」这件事。**

### ③ `微专业成绩算进主修绩点吗` —— 标了「不计入主修」

原文是「**不记入**主修专业毕业、学位授予审核条件」。「计」和「记」一字之差。

## 四、这意味着什么

v5 到 v8 一直在说「翘课、延毕这两条召回失败」。

**那不是检索的失败，是标注的失败。**

题目要求一份「根本没写这件事的文件」里出现某个特定词——无论检索怎么改，都不可能命中。

这也解释了一个之前没想通的现象：这两条在 `orig` 和 `rewrite` 两种模式下**都失败**，换什么检索策略都没用。

**评测集本身是测量装置的一部分。装置错了，量出来的所有结论都要打折。**

### 扩题立刻抓到 3 条检索失败

旧 39 条里「答非所问」是 0 条。扩到 57 条之后冒出 3 条：

| 题 | 应有来源 | 实际 |
|---|---|---|
| 单门课缺课太多会怎么样 | 学籍管理规定（缺课时数 / 三分之一） | 没命中 |
| 学术不端调查要几个人 | 学术不端查处细则（专家组） | 没命中 |
| 微专业成绩算进主修绩点吗 | 微专业管理办法（记入主修） | 没命中 |

**这正是扩评测集的意义**：39 条时「答非所问 0 条」看起来很漂亮，但那只是样本没覆盖到这些问法。

注意前两条都是「问题里带限定词」的类型——「单门课」「几个人」，而文档里写的是「累计缺课时数」「3-5 人的专家组」。**问法和文档措辞的鸿沟，在检索这一层还没解决。**
