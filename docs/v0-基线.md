## 三、评测结果

| 评测集 | 样本 | Recall@5 | MRR |
|---|---|---|---|
| 书面问法（`eval_set.jsonl`） | 50 | **96.00%** | 0.817 |
| 口语问法（`eval_set_colloquial.jsonl`） | 19 | **89.47%** | 0.816 |

**这个 96% 有水分，必须说清**：

| 水分来源 | 影响 |
|---|---|
| 问题按文档措辞编的 | 学生真实说法是"挂科了要不要重修"，不是"考核不合格的处理" |
| 池子只有 415 chunk、46 个文件 | 召回自然容易 |
| 只有一个领域 | 没有跨领域干扰 |

**真实场景会更低。** 面试时主动说这句，比被问穿强。

## 四、阈值 0.60 是标定出来的，不是拍的

用 50 条评测集量了相似度分布：

```
答对 48 条：最低 0.618   中位 0.708   平均 0.705
答错  2 条：最低 0.702   中位 0.736   平均 0.719   ← 反而更高
```

**两个结论**：

1. **相似度不能区分「答对」和「答错」** —— 答错的平均分还更高。因为它们不是检索偏了，是 chunk 切分和否定语义的问题。
2. **但能区分「领域内」和「越界」**：

| 问题 | 相似度 |
|---|---|
| 参军入伍能保留资格多久（答对） | 0.618 |
| **计算机学院有哪些老师（越界）** | **0.571** |
| **高等数学老师都有谁（越界）** | **0.516** |

**0.60 正好卡在中间**：答对的全部 > 0.618，越界的全部 < 0.571。

不同阈值的效果（误杀答对的 / 放行答错的）：

```
0.45~0.60 → 误杀 0 / 48，放行 2 / 2   ← 拦不住错误，但不误杀
0.65      → 误杀 4 / 48，放行 2 / 2
0.70      → 误杀 24 / 48（一半！），放行 2 / 2
```

**调阈值救不了答错的**（它们分数本来就高），所以 v1 必须从切分和检索算法上下手。

## 五、拒答设计

三段式，按相似度分流：

| 相似度 | 行为 |
|---|---|
| ≥ 0.70 | 直接生成 |
| 0.60 ~ 0.70 | **让模型判断「资料能不能回答」**，能才生成 |
| < 0.60 | 直接拒答 |

**灰区判断的关键**：要求模型**摘出依据那句话**，摘不出来就答"不能"。第一版只问"能不能回答"，结果它看到体育课安排里有老师名字就说"能"。

**拒答的输出必须三段**：

1. 明确说找不到（不编）
2. 说清能查的范围（学籍/学位/学分/辅修/转专业）
3. **指路**（按问题类型给真实去处）

```
任课教师 → 学院官网「师资队伍」页，或教务系统查课表
实习/实践 → 所在学院教务办，或教务处实践教学科
学生事务（宿舍/奖学金） → 学生处
兜底 → 教务处电话 029-83858041 · 邮箱 jwc@xust.edu.cn
```

指路信息全部来自官网，**不编造机构名**——编一个不存在的"实践教学科"比拒答更糟。

## 六、试错记录（三次踩坑，比成功更值钱）

### ① 第一次评测集污染：Recall@5 = 100%

**做法**：先跑检索 → 看召回哪个文件 → 再把它写成标准答案。

**结果**：15 条全中，14 条 rank=1。

**问题**：用答案凑标准，等于自己出题自己考。

**修法**：改成盲标——只读文档编问题和答案，全部编完才跑检索。重做后是 96%，**但这个数字是真的**。

> 保留的旧文件：`data/eval_set_污染版_勿用.jsonl`、`data/eval_result_污染版_勿用.json`

### ② 补抓「实践教学」栏目 —— 失败了

**判断**：学生问"实习能请假吗"，答不出来，因为漏抓了"实践教学"栏目。

**实际**：那个栏目 40 篇文章里，**全是「毕业设计」相关**（模板、答辩安排、抽检通知），**没有一条实习**。

**反而引入噪音**：20 个毕设模板（100–1300 字的纯表格）。

**修法**：把"模板""简报"加进噪音词，剔掉 60 个 chunk。

**教训**：**"多抓一个栏目"不等于"补上缺口"。** 要先确认目标内容是否在那个栏目里，而不是盲目扩大抓取范围。

### ③ 实训：`.doc` 26 个，PyMuPDF 和 python-docx 都读不了

**原因**：`.doc` 是 Office 97-2003 的二进制格式，不是 zip 包。

**修法**：用 Word COM（`win32com`）打开并取 `Content.Text`。

**关键优化**：**复用同一个 Word 实例**。每个都新建实例要 5 秒，26 个就是 2 分钟；复用后 30 秒。
