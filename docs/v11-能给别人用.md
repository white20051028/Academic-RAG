# v11：把它从「能跑」改成「能给别人用」（2026-11-06）

> 起因是一句用户提问：「这两个项目哪个能实操分享给同学老师，让他们使用？一直都只能在咱们自己的电脑上跑。」

## 一、先量了一下：到底差什么

拿项目去「给别人用」的标准检查，查出三个硬门槛：

| # | 问题 | 后果 |
|---|---|---|
| 1 | **13 处硬编码绝对路径** | 别人 clone 下来一个脚本都跑不起来 |
| 2 | `.env` 跨项目引用（P2 读 P1 目录的密钥） | P2 永远无法独立部署 |
| 3 | 换 key 要改文件 | 同学不可能做到 |

## 二、修了什么

### ① 路径统一到 `tools/paths.py`

```python
ROOT = Path(__file__).resolve().parent.parent   # 由文件位置推导
```

`.env` 优先项目自己的，找不到再退回旧位置（兼容本机老环境）。
`read_env()` 环境变量优先，其次 `.env`——方便 CI 和部署时用 `export` 覆盖。

**验证**：硬编码扫描 0 处；语法全过；23 个测试通过；实跑 `quick_eval` 1 条命中。

### ② 界面里填自己的 Key

侧栏加一个密码输入框。填了就用他的 key（花他的额度），不填用站点配置的。

换 key 时 `st.cache_resource.clear()`——否则检索器还持有旧 client，改了 key 不生效。

### ③ 反馈按钮

👍 / 👎 落盘到 `data/feedback.jsonl`（进 `.gitignore`，可能含个人信息）。

**为什么这个比功能重要**：现在评测集是我自己编的题，真实用户提问才是下一批题的来源，也是「有真实用户」这件事的证据。

### ④ 修数据管道的误杀

原来 `noise_reason()` 对**文件名乱码**一刀切剔除。

实测 39 个乱码文件里混着《学位论文作假行为处理实施细则》《本科毕业设计（论文）相似度检测实施办法》——**编码问题连累了内容**。

判据改成看内容有没有「第X条」条文结构：

```python
def _looks_like_policy(text: str) -> bool:
    return bool(re.search(r"第[一二三四五六七八九十百\d]+条", text[:3000]))
```

用条文结构而不是关键词：`通知`/`办法` 在文件名里到处都有，误判率太高；`第三条` 只有真条文才有。

**结果**：141 文件 / 1084 chunk → **146 文件 / 1106 chunk**（46.7 万字）。

## 三、评测：变差了，而且我知道为什么

| | 之前 | 现在 |
|---|---|---|
| 该答 46 条 | 真答对 34 | **33** |
| 答非所问 | 3 | **4** |
| 该拒 11 条 | 11 | 11 |
| 总正确 | 45/57 = 78.9% | **44/57 = 77.2%** |

**掉的是「论文抄袭会被取消学位吗」。**

新入库的《学位论文作假处理实施细则》比原来的《学术不端查处细则》更具体，检索召回了更准的文件——但评测集的 `expect_source` 只认后者，于是判为没命中。

**这不是数据错了，是评测标注不够宽。** 一道题有两个合理答案来源时，`is_hit()` 只支持一个。

**数据变多不等于分数变高。** 这条记在这儿，免得下次又以为"加数据一定涨"。

## 四、分享的三条路（写进 README 了）

| 范围 | 做法 | 状态 |
|---|---|---|
| 同 WiFi | `streamlit run app.py`，给内网 IP | ✅ 已验证 |
| 公网 | `cloudflared tunnel --url http://localhost:8501` | ✅ 已验证（手机流量访问成功） |
| 固定域名/期长期 | 命名隧道 / 云服务器 | 未做 |

隧道三个坑：免费版**重启换地址**、**电脑必须开着**、**用的是站长的 key 和额度**（所以 ② 必须先做）。
