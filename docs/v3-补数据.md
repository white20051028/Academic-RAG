## 踩的坑：噪音词把制度文件误杀了

补完《重修管理办法》后，检索「挂科了要重修吗」**还是失败**。

查索引才发现：**保留文件数从 69 只涨到 71**（应该 72）。

原因在 `NOISE_WORDS`：

```python
NOISE_WORDS = ("重修", "考试安排", "补考", ...)
               ↑ 本意是过滤「重修名单」「重修通知」
```

结果把 **《本科生课程重修管理办法》** 也剔掉了 —— 它的文件名里有"重修"。

> **关键词过滤永远有误杀风险。** 而且这个 bug 从外面看不出来：
> 检索结果只是"没找到"，你不会怀疑"文件根本没进索引"。

**修法：制度类文件名永不剔除。**

```python
POLICY_WORDS = ("管理办法", "实施细则", "管理规定", "实施办法",
                "暂行办法", "暂行规定", "工作细则", "查处细则")

# 先判豁免，再判噪音
if any(w in name for w in POLICY_WORDS):
    return None
```

修完：保留 72 个、449 chunk。而"重修名单""重修通知"仍被正确剔除。

## 教训

**① 补数据要有对应的评测题，否则量不出来**

补完 3 份文件后，原来的 19 条口语题**分数一点没动**——因为它们不涉及重修。加 5 条重修题之后，才看到变化。

**② 「检索不到」有两种原因，症状一样**

| 原因 | 症状 | 怎么区分 |
|---|---|---|
| 数据里没有 | 检索不到 | 查 `index_stats.json` 的 `kept` 列表 |
| 数据里有但被过滤了 | **检索不到（一模一样）** | 同上 |

**所以排查"检索不到"时，第一步永远是：先确认这份文件到底进没进索引。**
